Este projeto é um protótipo desenvolvido em Python que permite o cadastro de cuidadores, visualização da lista de cadastrados e o registro de convocações para plantões.

Funcionalidades principais:

-Cadastro de cuidadores (Nome, Telefone e Formação).

-Listagem de cuidadores cadastrados.

-Convocação para plantões com registro de data e período.

-Histórico de convocação disponível para consulta.

O objetivo do projeto é demonstrar usabilidade e funcionamento do sistema de forma clara.

 Execução:

```bash
python main.py
